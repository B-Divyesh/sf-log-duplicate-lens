# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This project uses semantic versioning.

## [0.1.0] - 2026-08-28

### Added

- Local analysis for Loki query responses, Loki/JSONL records, JSON event arrays, and newline-delimited text.
- Configurable timestamp tolerance, dynamic-field normalization, redaction, label filtering, and bounded sampling.
- Human evidence report, stable JSON schema, automation exit codes, and conservative inflation estimates.
